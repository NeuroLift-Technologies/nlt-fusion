# NLT World Engine — Godot Runtime

The **authoritative world engine**, replacing the UE 5.8 runtime in its entirety per Joshua's ENG-002 decision (2026-10-07). The UE tree is retained only as a frozen, non-authoritative reference. Runs on Godot 4.7.2 (.NET / mono) with .NET 8.

> Godot owns the physical simulation. Fusion owns semantic cognition and intents. Historical migration and renderer plans are superseded by ENG-002; they are not current architecture or implementation instructions.

## Run

Open this folder (`world-engine-godot/`) as a project in **Godot 4.7.2 .NET (mono)** — the standard build will not run the C# code.

- Main scene: `Main.tscn` → `Main.cs` → `WorldView` (procedural open world + state-feed fixture)
- Interiors (FBX via ufbx): `workplace_level.tscn`, `personal_level.tscn`, `social_level.tscn`, `academic_level.tscn`, each a thin wrapper around `assets/levels/<Name>_Level.fbx`

## Layout

| Path | Purpose |
|---|---|
| `Main.tscn` / `Main.cs` | Entry scene; `Main` extends `WorldView` |
| `WorldView.cs` | Camera, Sky3D sky, state-feed load, builders (terrain/water/settlement/vegetation) |
| `StateFeedLoader.cs` | Loads + validates `fixtures/state-feed.sample.json` against `../docs/contracts/state-feed-v1.md` |
| `TaskAnchor.cs` | Task-anchor model (affordance axes, reservations, need matching) — model only; placement open |
| `TerrainBuilderPhysics.cs` | Intentional empty placeholder (Phase C.1 collision comes from the import post-processor, not runtime nodes) |
| `TerrainBuilder.cs` / `WaterBuilder.cs` / `SettlementBuilder.cs` / `VegetationBuilder.cs` | Procedural open world |
| `fixtures/state-feed.sample.json` | Static state fixture until the Fusion bridge exists |
| `assets/levels/*.fbx` (+ `.import`) | Four interior level exports from UE; collision via `add_physics_post_import.gd` (`EditorScenePostImport`) on next import |
| `addons/sky_3d/` | Sky3D day/night atmospheric sky (ratified by Joshua; SkyBuilder.cs/Daylight.cs retired) |
| `assets/levels/add_physics_post_import.gd` | Post-import script generating `StaticBody3D` + trimesh `CollisionShape3D` from `UCX_*` hulls |
| `strip_fbx.gd` | Utility script for stripped FBX variants (watched by plan item 0.2 — not yet committed blind) |
| `demo/` | Sky3D demo scene (upstream sample, not part of the simulation) |
| `RenderStripped.*`, `SK_SimBody_Base.fbx` | Untracked, unexamined — do **not** commit blind (plan §8, 0.2) |

## Important notes

- **OpenWorld_Level has no FBX export** (World Partition + runtime generation); the open world is procedural by design (`RENDERER-PLAN.md` §4). The four FBX files are interiors only.
- `meshes/create_shapes` is **not** a valid FBX/ufbx import option — the editor strips it. Collision is generated by the post-import script; if you change FBX import settings, delete `.godot/imported/*Level*` and re-import once.
- Incident-report line-ending/CRLF edits on `.import` files to an orphaned editor/session state — prefer doing import edits in the editor's Import dock.
- `../docs/active-threads.md` is the current work tracker; read `../AGENTS.md` before working here. The legacy `RENDERER-PLAN.md` and `MIGRATION-PLAN.md` are superseded historical records.
