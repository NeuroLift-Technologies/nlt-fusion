## Usage

Outdoor open-world terrain for the procedural island/district layout generated by
`NLTWorldGeneratorSubsystem`. These assets provide the physical terrain mesh,
materials, and textures for different biome types.

## Integration Points

- `NLTWorldGeneratorSubsystem::GenerateDistricts()` — district type → terrain type
- `PCG/EnvironmentScatter` — terrain-based scatter rules
