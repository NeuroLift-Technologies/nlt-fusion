# UE Asset Production

Authorized for OpenCode lane: environment construction, world presentation, lighting, materials, spatial composition, environmental assets, and scene organization.

## Must Escalate
- Changes to simulation semantics
- Changes to agent authority
- Changes to global world-state contracts
- Modifications that materially affect scenario behavior

## Must Not Do
- Treat visual correctness as simulation correctness
- Changing simulation behavior solely for visual convenience without disclosure
